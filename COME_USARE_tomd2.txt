================================================================================
              COME USARE  tomd2  +  convert  (convertitore universale)
            Conversione di QUALUNQUE formato verso QUALUNQUE altro
                  Gratis, in locale, senza GPU
================================================================================

A COSA SERVE
------------
Due tool, una sola cartella:

(1) tomd2.py      -> conversione AD ALTA FEDELTÀ verso Markdown.
                     Mantiene testo, tabelle, formule LaTeX, immagini, page-image.
                     170 estensioni accettate in input.

(2) convert.py    -> convertitore UNIVERSALE: qualunque formato -> qualunque altro,
                     dove ha senso. Se la coppia non è supportata, mostra un errore
                     chiaro con i formati di destinazione disponibili.

(3) tomd2_gui.py  -> interfaccia grafica per entrambi (drag-and-drop file/cartelle,
                     selettore "Converti in" dinamico, log in tempo reale).

I file ORIGINALI non vengono mai modificati o cancellati.


================================================================================
PARTE 1 - INSTALLAZIONE UNA TANTUM
================================================================================

PASSO 1.1 - Python 3.10+
------------------------
Scarica da https://www.python.org/downloads/ con la spunta "Add python.exe to PATH".
Verifica: `python --version` in PowerShell.


PASSO 1.2 - Librerie Python (un solo comando)
---------------------------------------------
    python -m pip install -U pymupdf pymupdf4llm markitdown openpyxl python-pptx ^
        pandas pillow img2pdf cairosvg pypandoc tkinterdnd2 openai-whisper

A cosa servono:
  pymupdf, pymupdf4llm  estrae testo da PDF ad alta fedeltà
  markitdown            converte docx/html/epub/json/xml/...
  openpyxl              Excel pulito (no NaN, no Unnamed)
  python-pptx           PowerPoint, estrae le immagini
  pandas                CSV/JSON/Excel/Parquet
  pillow, img2pdf       immagini
  cairosvg              SVG
  pypandoc              wrapper Python di Pandoc
  tkinterdnd2           drag-and-drop nella GUI
  openai-whisper        trascrizione audio/video (richiede ffmpeg)


PASSO 1.3 - Strumenti esterni (per il convertitore universale)
--------------------------------------------------------------
Apri PowerShell e lancia:

    winget install --id JohnMacFarlane.Pandoc -e
    winget install --id TheDocumentFoundation.LibreOffice -e
    winget install --id Gyan.FFmpeg -e
    winget install --id ImageMagick.ImageMagick -e

A cosa servono:
  Pandoc          documenti testuali (md, docx, html, epub, tex, ...)
  LibreOffice     Office <-> PDF (docx/xlsx/pptx <-> pdf, ecc.)
  FFmpeg          audio/video (mp3/wav/mp4/mkv/gif, ...)
  ImageMagick     fallback per formati immagine esotici

Se manca uno strumento al momento della conversione, lo script NON crasha:
ti dice quale manca e il comando winget per installarlo.


================================================================================
PARTE 2 - USO DEL CONVERTITORE UNIVERSALE (convert.py)
================================================================================

ESEMPI BASE
-----------
Conversione singola:
    python convert.py relazione.docx --to pdf
    python convert.py figura.png --to jpg
    python convert.py foglio.xlsx --to csv

Nome di output esplicito:
    python convert.py relazione.docx relazione_finale.pdf

Batch (tutti i file di un tipo):
    python convert.py *.docx --to pdf
    python convert.py *.png --to webp
    python convert.py *.mp4 --to mp3

PDF -> Markdown (alta fedeltà, motore di tomd2):
    python convert.py corso.pdf --to md
    python convert.py *.pdf --to md

LISTA DELLE CONVERSIONI POSSIBILI
---------------------------------
    python convert.py --list

Mostra tutte le coppie sorgente -> destinazione raggruppate per categoria.

GESTIONE ERRORE QUANDO NON HA SENSO
-----------------------------------
    python convert.py foglio.xlsx --to mp3

Risposta:
    [KO] Conversione .xlsx -> .mp3 NON supportata.
       Categoria sorgente: Documenti Office   |   destinazione: Audio
       Da .xlsx puoi convertire verso: .csv, .docx, .html, .json, .markdown,
                                        .md, .odt, .parquet, .pdf, .pptx, .tsv, .txt.
       Esempio: --to csv

OPZIONI UTILI
-------------
  --overwrite               sovrascrivi output esistenti (default attivo)
  --no-overwrite            salta se output esiste già

  Markdown:
  --page-image-dpi 200      pagine più nitide (default 150)
  --no-page-images          niente immagini delle pagine
  --vector-threshold 5      soglia drawings per renderizzare pagina (default 3)
  --media-dir figure        cambia cartella raccoglitrice (default 'media')
  --engine pymupdf4llm      forza motore tomd2 (auto/pymupdf4llm/marker/ocr_scan/...)
  --force-ocr               forza OCR (solo motore marker)
  --block-size 15           marker a blocchi di 15 pagine (RAM 8 GB)
  --whisper-model base      tiny/base/small/medium/large per audio/video

  Multimediali (audio/video/immagini):
  --quality 90              jpg/webp 1-100
  --width 1024 --height 768 ridimensiona immagini
  --fps 24                  fps per video o gif
  --bitrate 192k            audio/video
  --image cover.png         per audio->video (sfondo)

  Dati tabellari:
  --sheet "Foglio2"         specifica foglio xlsx
  --sep ";"                 separatore csv


================================================================================
PARTE 3 - USO DELLA GUI (tomd2_gui.py)
================================================================================
Apri:
    python tomd2_gui.py

CARATTERISTICHE
1. Trascina file/cartelle sulla lista in alto (drag-and-drop)
2. Combobox "Converti in" si AGGIORNA DINAMICAMENTE in base ai file caricati:
   ti mostra solo i formati di destinazione raggiungibili da TUTTI i tuoi file.
3. Modalità Markdown: scegli ".md" e tomd2 fa conversione ad alta fedeltà
4. Modalità Universale: scegli ".pdf", ".docx", ".mp3", ".jpg", ecc. e usa il router
5. Le impostazioni si salvano in `.tomd2_gui_config.json` (ritrovi tutto al riavvio)
6. "MD snello (no <details>)" - checkbox per ridurre boilerplate (suggerito da Gemini)
7. Keep-awake: il PC non si sospende durante la conversione
8. Resume support: marker a blocchi riprende dai blocchi già fatti


================================================================================
PARTE 4 - CATEGORIE E CONVERSIONI SUPPORTATE
================================================================================
(elenco abbreviato; per la lista completa: `python convert.py --list`)

DOCUMENTI TESTUALI (via Pandoc)
  .md .docx .odt .rtf .html .epub .txt .tex
  -> tutte le combinazioni fra loro + .pdf (con fallback automatico)

DOCUMENTI OFFICE / PDF (via LibreOffice)
  .docx .doc .xlsx .xls .odt .ods .pptx .ppt .odp .pdf
  -> .pdf .docx .odt .html .txt .xlsx .csv .pptx (e .pdf -> .docx ecc.)

DATI TABELLARI (via pandas)
  .csv .tsv .xlsx .xls .ods .json
  -> .csv .tsv .xlsx .json .parquet
  (con riconoscimento intelligente di titoli/header/unità di misura)

IMMAGINI (via Pillow + img2pdf + cairosvg)
  .png .jpg .webp .tiff .bmp .gif .svg
  -> .png .jpg .webp .tiff .bmp .gif .pdf .ico
  (HEIC richiede in più: pip install pillow-heif)

AUDIO/VIDEO (via FFmpeg)
  Audio: .mp3 .wav .flac .aac .ogg .m4a .opus .wma
  Video: .mp4 .mov .avi .mkv .webm .flv .wmv .m4v
  Conversioni:
    audio -> audio        (riconversione)
    video -> audio        (estrai colonna sonora)
    video -> video        (transcoding)
    video -> gif          (clip animata)
    audio -> video        (audio + immagine fissa)
    gif -> mp4            (compatibilità)

MARKDOWN AD ALTA FEDELTÀ (via tomd2)
  Tutti i 170 formati supportati da tomd2 -> .md
  (PDF, Office, code Python/JS/C..., Jupyter, email .eml, archive .zip, ...)

PARTE 5 - CASI D'USO TIPICI
================================================================================

A) Voglio passare un libro/dispense a un'IA
    python convert.py *.pdf --to md
    -> ottieni .md ad alta fedeltà con tabelle, formule LaTeX, page-image dei diagrammi.

B) Voglio convertire una presentazione in PDF
    python convert.py presentazione.pptx --to pdf

C) Voglio estrarre l'audio da un video
    python convert.py lezione.mp4 --to mp3

D) Voglio fare un GIF da un breve video
    python convert.py clip.mp4 --to gif --fps 12

E) Ho un foglio Excel: lo voglio in CSV e in JSON
    python convert.py dati.xlsx --to csv
    python convert.py dati.xlsx --to json

F) Voglio trascrivere un audio
    python convert.py podcast.mp3 --to md --whisper-model base

G) Voglio convertire foto in PDF album
    python convert.py *.jpg --to pdf

H) Documento Word -> PDF
    python convert.py relazione.docx --to pdf
    (se manca LaTeX, usa fallback automatico via LibreOffice)


================================================================================
PARTE 6 - MIGLIORIE QUALITÀ MARKDOWN (suggerite da 3 LLM)
================================================================================
Le 3 IA Gemini, ChatGPT e DeepSeek hanno recensito la qualità di tomd2.
Le loro segnalazioni sono state integrate:

1. FIX MOJIBAKE (DeepSeek):
   - Caratteri sbagliati "тАФ" "┬«" "┬»" si trasformano in "—" "«" "»" automaticamente.

2. TESTO ORIGINALE QUANDO LE FORMULE DIVENTANO IMMAGINI (Gemini):
   - Se pymupdf4llm "intrappola" una formula come immagine ma il PDF aveva il
     testo selezionabile, il file .md aggiunge una sezione "Testo grezzo" col
     contenuto raw da pymupdf, così l'IA può comunque leggere le formule.

3. MD SNELLO (Gemini):
   - Flag --lean-md (oppure checkbox nella GUI) per usare link compatti
     invece di <details><summary>, riducendo i token "boilerplate".


================================================================================
PARTE 7 - PROBLEMI TIPICI E SOLUZIONI
================================================================================

PROBLEMA: "ModuleNotFoundError: pymupdf4llm" o simile
SOLUZIONE: ripeti il PASSO 1.2.

PROBLEMA: "Pandoc non installato" / "soffice non trovato"
SOLUZIONE: hai saltato il PASSO 1.3. Lancia i comandi winget.
           Riavvia PowerShell dopo l'installazione.

PROBLEMA: PDF scansionato -> .md è vuoto
CAUSA:    Non ha testo selezionabile (sole immagini).
SOLUZIONE: usa marker:
    python tomd2.py scansione.pdf --engine marker --force-ocr --block-size 15
  (lento sul tuo PC senza GPU: ~1h per 15 pagine).

PROBLEMA: marker si impalla / Out Of Memory
SOLUZIONE: blocchi più piccoli:
    --block-size 10
  + chiudi browser/Office/Teams.

PROBLEMA: voglio rifare conversioni grandi e perdo blocchi a metà
SOLUZIONE: tomd2 con marker ha RESUME automatico. Rilancia: i blocchi
           già fatti vengono SALTATI.

PROBLEMA: PDF scansionato CON OCR (es. Anna's Archive)
SOLUZIONE: tomd2 lo rileva da solo e usa l'engine 'ocr_scan' (testo OCR
           preservato + page-image come backup visivo).

PROBLEMA: Audio -> .md ma manca whisper
SOLUZIONE: pip install -U openai-whisper + installa ffmpeg via winget.

PROBLEMA: file .mobi/.azw3/.djvu non si convertono
SOLUZIONE: serve Calibre (https://calibre-ebook.com). Una volta installato:
    ebook-convert "libro.mobi" "libro.epub"
  poi: python tomd2.py "libro.epub"



================================================================================
NOVITA' - OCR VELOCE E NUOVE CONVERSIONI
================================================================================

OCR TESSERACT (nuovo, automatico):
  - Immagini (.png .jpg ...) -> .md : ora usano Tesseract (SECONDI, non ore).
    Il testo dentro l'immagine viene estratto e messo nel .md.
  - PDF scansionati SENZA testo -> .md : OCR automatico pagina per pagina.
    (marker resta disponibile con --engine marker per qualita' massima)
  - Lingue: italiano+inglese di default. Cambia con --ocr-lang (es. "deu").

NUOVE CONVERSIONI:
  - PDF -> immagini:   python convert.py doc.pdf --to png   (multipagina: _p001, _p002...)
  - md/docx -> PPTX:   python convert.py appunti.md --to pptx (ogni titolo = slide)
  - audio/video -> sottotitoli: python convert.py lezione.mp4 --to srt
                                 python convert.py voce.wav --to vtt
    (usa Whisper: --whisper-model tiny/base/small per velocita'/qualita')
  - HEIC (foto iPhone) ora supportato (pillow-heif installato)
  - .ods (LibreOffice Calc) ora convertibile anche con pandas (odfpy installato)


AI-PACK: PDF PIENI DI IMMAGINI -> .MD LEGGERO PER LE IA (nuovo)
  Problema: slide fotografiche (astronomia, arte, medicina) producono md +
  immagini PNG da centinaia di MB, che nessuna chat IA accetta.
  Soluzione:
      python tomd2.py "*.pdf" --engine ai_pack --overwrite
  Ogni pagina diventa UNA immagine WebP (qualita' 70, lato max 1568 px = la
  risoluzione massima che Claude/GPT usano davvero) + tutto il testo della
  pagina (layer PDF oppure OCR automatico sulle pagine senza testo).
  Riduzione tipica: 3-20x. Qualita' visiva: testo e diagrammi leggibili.
  Opzioni: --ai-quality 60..85 (peso/qualita'), --ai-max-side 1200 (piu' leggero).
  Dalla GUI: Motore = ai_pack.

XLSX -> PDF MIGLIORATO:
  - fit-to-width automatico + orientamento orizzontale per fogli larghi
  - larghezza colonne auto-adattata: niente testo tagliato in stampa
